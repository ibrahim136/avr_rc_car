# \# AVR Multi-Mode RC Car

# 

# An embedded systems project built on the \*\*AVR microcontroller platform\*\* featuring an RC vehicle capable of autonomous navigation and wireless manual control across four distinct operating modes.

# 

# \## Operating Modes

# 

# 1\. \*\*Mobile Control:\*\* Manual driving and speed regulation over Bluetooth via smartphone.

# 2\. \*\*Obstacle Avoidance:\*\* Real-time distance measurement and obstacle avoidance using sensor integration (Ultrasonic / IR).

# 3\. \*\*Line Follower:\*\* High-accuracy track following using IR floor sensors.

# 4\. \*\*Maze Solver:\*\* Autonomous navigation and shortest-path trajectory solving through grid mazes.

# 

# \## Tech Stack \& Hardware

# \- \*\*Platform / Architecture:\*\* AVR Microcontroller

# \- \*\*Language:\*\* Embedded C

# \- \*\*Peripherals \& Protocols:\*\* GPIO, PWM (Timer), UART (Bluetooth), External Interrupts, ADC
